# دليل نظام النقاط والولاء - IGTaxi

## 📋 نظرة عامة

نظام شامل لنقاط الولاء يسمح للسائقين والعملاء بكسب النقاط واستبدالها بمكافآت مختلفة. النظام يتضمن مستويات متدرجة وبرنامج إحالة ومزايا حصرية.

## 🏗️ البنية التقنية

### قاعدة البيانات
- **create-loyalty-system.sql**: إعداد قاعدة البيانات الكاملة
  - 7 جداول رئيسية
  - دوال PostgreSQL للعمليات المتقدمة
  - نظام الصلاحيات RLS
  - مؤشرات الأداء والفهارس

### طبقة الخدمات
- **loyalty-service.ts**: خدمة TypeScript شاملة
  - 20+ وظيفة للتعامل مع النقاط
  - إدارة المكافآت والاستبدال
  - نظام الإحالة والمراجع
  - تحليلات وإحصائيات

### واجهات المستخدم
- **CustomerLoyaltyDashboard.tsx**: لوحة تحكم العملاء
- **DriverLoyaltyDashboard.tsx**: لوحة تحكم السائقين
- **loyalty-manager-new.ts**: مدير العمليات التلقائية

## 🎯 المميزات الأساسية

### 1. كسب النقاط
#### للسائقين:
- **10 نقاط** لكل رحلة مكتملة
- **20 نقطة** للحصول على تقييم 4.5+ نجوم
- **15 نقطة** للرحلات الطويلة (+10 كم)
- **50 نقطة** للنشاط الأسبوعي (10+ رحلات)
- **30 نقطة** للانضباط (3+ أيام بدون تأخير)
- **200 نقطة** لكل دعوة سائق ناجحة
- **100 نقطة** مكافأة التسجيل

#### للعملاء:
- **5 نقاط** لكل رحلة
- **10 نقاط** لكتابة تقييم
- **100 نقطة** لكل دعوة عميل ناجحة
- **50 نقطة** مكافأة التسجيل

### 2. المستويات والدرجات
| المستوى | النقاط المطلوبة | المزايا |
|---------|----------------|---------|
| 🥉 Bronze | 0-499 | خصم 5% على الرحلات |
| 🥈 Silver | 500-1499 | خصم 10% + أولوية الدعم |
| 🥇 Gold | 1500-2999 | خصم 15% + عروض حصرية |
| 💎 Platinum | 3000-4999 | خصم 20% + مزايا VIP |
| 👑 VIP | 5000+ | خصم 25% + مدير شخصي |

### 3. المكافآت والاستبدال
#### للسائقين:
- **رصيد نقدي**: 500 نقطة = 10 دينار
- **وقود مجاني**: 300 نقطة = 5 لتر
- **صيانة مخفضة**: 400 نقطة = خصم 50%
- **تأمين إضافي**: 600 نقطة = شهر مجاني

#### للعملاء:
- **رحلة مجانية**: 200 نقطة
- **خصم 50%**: 100 نقطة
- **ترقية السيارة**: 150 نقطة
- **توصيل مجاني**: 80 نقطة

### 4. نظام الإحالة
- **كود شخصي** لكل مستخدم
- **نقاط فورية** عند التسجيل بالكود
- **مكافآت مضاعفة** للإحالات الناجحة
- **تتبع دقيق** لجميع الإحالات
