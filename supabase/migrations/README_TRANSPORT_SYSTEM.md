# Transport System Database Migration

## ترتيب تشغيل Migrations

يجب تشغيل ملفات migration بالترتيب التالي:

### 1. النظام الأساسي
```sql
-- 1. BASE_SYSTEM_SETUP.sql (النظام الأساسي)
-- 2. 20250119_001_create_businesses.sql (ملفات الأعمال)
-- 3. 20250119_002_create_main_profiles_system.sql (نظام الملفات الشخصية)
-- 4. 20250119_007_create_common_system_tables.sql (الجداول المشتركة)
-- 5. 20250119_010_fix_existing_policies.sql (إصلاح السياسات)
```

### 2. نظام النقل الجديد
```sql
-- 6. 20250119_011_create_transport_system.sql (نظام النقل الكامل)
```

## محتويات نظام النقل

### الجداول الرئيسية:

1. **transport_requests** - طلبات النقل
   - تفاصيل الحمولة (نوع، وزن، أبعاد)
   - مواقع الاستلام والتسليم
   - الميزانية والعملة
   - حالة الطلب

2. **transport_offers** - عروض الناقلين
   - سعر العرض
   - تفاصيل المركبة
   - توقيت التسليم المتوقع
   - حالة العرض

3. **transport_trips** - رحلات النقل
   - تتبع حالة الرحلة
   - التقييمات
   - المعلومات المالية (العمولة 10%)

4. **transporter_profiles** - ملفات الناقلين
   - معلومات الشركة
   - المركبات
   - منطقة الخدمة
   - التقييمات

5. **transport_contracts** - العقود
   - عقود الشركات والمدارس
   - عقود العمال والموظفين
   - عقود شخصية

### المميزات:

✅ **نظام العمولة**: 10% عمولة تلقائية على كل رحلة  
✅ **تتبع الموقع**: مواقع الاستلام والتسليم مع الإحداثيات  
✅ **أنواع حمولة متعددة**: 8 أنواع من البضائع  
✅ **نظام التقييمات**: تقييم ثنائي الاتجاه  
✅ **دعم العملات**: نظام عملات ديناميكي  
✅ **العقود طويلة المدى**: 6 أنواع عقود  
✅ **أمان البيانات**: RLS policies كاملة  

### الوظائف المساعدة:

- `calculate_commission()` - حساب العمولة
- `update_transporter_rating()` - تحديث تقييم الناقل
- `update_completed_trips_count()` - تحديث عدد الرحلات

### العروض (Views):

- `transport_requests_with_customer` - طلبات مع بيانات العميل
- `transport_offers_with_transporter` - عروض مع بيانات الناقل  
- `transport_trips_complete` - رحلات كاملة بجميع التفاصيل

## كيفية التطبيق

1. تأكد من تشغيل النظام الأساسي أولاً
2. قم بتشغيل migration نظام النقل:
   ```bash
   supabase migration up 20250119_011_create_transport_system
   ```

3. تحقق من إنشاء الجداول:
   ```sql
   SELECT table_name FROM information_schema.tables 
   WHERE table_schema = 'public' 
   AND table_name LIKE 'transport%';
   ```

## ملاحظات مهمة

- جميع الجداول تدعم RLS (Row Level Security)
- العمولة الافتراضية 10% قابلة للتعديل
- نظام التقييمات من 1-5 نجوم
- دعم كامل للعملات المتعددة
- إمكانية تتبع الرحلات بالوقت الفعلي
